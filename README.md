# airplane-embedded-system-program
hypothetical airplane stabilizer and program in c++
Basically this program creates a random starting height and random turbulence that ether reduces or increases that starting height
After 3 seconds if the airplane makes it back into a safe threshold then it's a win and lands
if not then it reroutes. 
This program uses random numbers, arrays, ints, references and functions 
The speed of the increasing can be improved but im ready to start working on my next project.
